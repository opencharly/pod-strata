# 2026.327.0603 — fix(import)!: pin pod-cdi at the release built on the post-#420 distro-arch

## Summary

`pod-cdi` was pinned at `v2026.325.1329`, whose own `arch:` import still names `distro-arch:v2026.325.1112` — a tree from **before** the build-vocabulary cutover. That tree's `box/arch-test` carries `build: [pac, aur]`, and since `spec v0.2026326.2226` (`opencharly/spec#420`) `aur` is a routed builder and never a build format, so **any** project composing this namespace failed at project LOAD, before a single build step.
