# 2026.327.2257 — feat(bed)!: adopt layer-strata's default posture, and prove it on a disposable GPU pod

## Summary

`layer-strata v2026.327.2013` makes the deployed posture the candy's **default**: `STRATA_SET: vram-reserve-mib=512 idle-unload=300`, with pictures ON by the candy's own `VISION: cpu`. This repo composes that candy, so it moves to that release and gains the bed that proves the **default** rather than an override.

**Scope of the "default" claim, stated up front:** the two `STRATA_SET` values (five-minute idle unload, 512 MiB picture reserve) and `VISION` are the candy's defaults and the bed sets neither. `CONTEXT` IS a bed-supplied model parameter (the store's own preset carries the same value), so the projection assertion proves the request is honoured — not that the candy defaults the context.

**`check-strata-idle-pod`** is that bed. `check-strata-gpu-pod` pins its own `STRATA_SET` for determinism (`idle-unload=0`, reserve 512) and therefore can never prove the default; this bed carries **no `STRATA_SET` and no `VISION`** and asserts:

- `/health` reports the model **LOADED** — the anchor that makes the next assertion meaningful — with **pictures ON** by the candy's default and the context this deployment asks for;
- the model is **RELEASED** after five idle minutes with no request;
- the next request **RELOADS** it and is answered.
